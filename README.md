# Template de site — Eko

Template estático em HTML, CSS e JavaScript para personalizar e clonar para novos clientes.

## Estrutura
- `index.html` — página inicial, menu, serviços e contato.
- `servicos.html` — catálogo de serviços.
- `servicos/modelo-servico.html` — modelo de página individual de serviço.
- `politica-de-privacidade.html` — modelo inicial de política de privacidade.
- `assets/css/styles.css` — estilos e layout responsivo.
- `assets/js/script.js` — menu, menu suspenso e formulário de WhatsApp.

## Antes de publicar
1. Substitua o nome e a identidade visual da clínica.
2. Em `assets/js/script.js`, configure `whatsappNumber`, `businessName`, `phoneDisplay`, `address` e `hours`.
3. Atualize todos os textos, serviços, links, endereço, horários e informações profissionais.
4. Configure o Google Tag Manager e demais ferramentas de mensuração com identificadores próprios do cliente. Não reutilize IDs de outro negócio.
5. Revise a política de privacidade de acordo com as tecnologias e práticas reais.
6. Teste o menu em celular, todos os links, o formulário e o WhatsApp.
7. Faça testes de conversão no Google Ads/Analytics antes de investir em campanhas.

## Observações
- O formulário não armazena dados em banco; ele prepara uma mensagem no WhatsApp.
- O clique no WhatsApp não significa, por si só, que uma conversa foi enviada ou que houve agendamento.
- Os links e os textos de serviços são exemplos e precisam ser personalizados.
- O template não contém credenciais privadas nem identificadores de medição específicos.
